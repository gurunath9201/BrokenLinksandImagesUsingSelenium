# 🔗 Broken Links and Images Checker using Selenium Java

This project automates the verification of **broken links** and **broken images** on a website using **Selenium WebDriver**, **Java**, and **HttpURLConnection**.

## 🚀 Technologies Used

- Java
- Selenium WebDriver
- Maven
- EdgeDriver
- HttpURLConnection

## 📂 Project Structure

```
src
└── main
    └── java
        └── com
            └── pp
                ├── BrokenLinksTest.java
                └── BrokenImagesTest.java
```

## ✅ Features

- Detects Broken Links
- Detects Broken Images
- Prints HTTP Response Code
- Identifies Valid and Broken URLs
- Uses Selenium with HttpURLConnection

## 🛠️ Maven Dependency

```xml
<dependency>
    <groupId>org.seleniumhq.selenium</groupId>
    <artifactId>selenium-java</artifactId>
    <version>4.40.0</version>
</dependency>
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Install Maven dependencies.
4. Run:
   - `BrokenLinksTest.java`
   - `BrokenImagesTest.java`

## 📌 Output

- Total number of links/images
- Valid Links
- Broken Links
- Broken Images
- HTTP Response Code and Message
